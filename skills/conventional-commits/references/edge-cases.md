# Edge cases

## Reverts

Use the `revert` type and reference the reverted commit's SHA in the footer:

```
revert: feat(cli): add --dry-run flag

Refs: 676104e
```

## Merge commits

Leave merge commits generated by git as they are. Squash-merge titles should
follow the same format as a normal commit.

## Monorepos

Use the package or app name as the scope (`feat(web): ...`, `fix(api-gateway): ...`).
If a change spans several packages, omit the scope rather than listing them all.

## Multiple issues

One footer per reference:

```
Refs: #12
Closes: #34
```
